# README

[cfiler](https://github.com/crftwr/cfiler) (内骨格) customization.

## Install

Run:

```
uv run install.py
```

to create junction of `CraftFiler` to AppData.

## Development Setup

This project uses [uv](https://docs.astral.sh/uv/) to match the Python version bundled with keyhac.

To set up the development environment, run:

```
uv sync
```
